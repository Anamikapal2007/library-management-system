Policy & Guidelines

Simple rules for maintaining accurate catalog and circulation records.

📚

Catalog rules

  • Each book ID must be unique (IDs are matched without regard to case).
  • Book title and author name are required.
  • Publication year must be a valid year up to the current year.
  • Available copies must be a non-negative whole number.
🔄

Circulation rules

  • A book can be issued only when a copy is available.
  • Issuing a book decreases available copies by one.
  • Returns must match an outstanding book and student issue record.
  • A valid return increases available copies by one.
💾

Data & privacy

  • Catalog and loan data are stored in this browser on this device.
  • Data are not automatically shared or synchronized across devices.
  • Use Export CSV to save a copy of the book catalog.
  • Returned loan records remain in local history; only active loans show in Active Loans.
